# Finish round 11/14, b40: 08007B40

## Finding

08007B40 was not unmatched code. It is the restart label inside the race main
`func_08007B28`, which has been installed as exact C since 11/3. That
replacement is 2,292 bytes, 08007B28-0800841C, and covers all 2,268 bytes of
the 08007B40 entry. Those bytes were already counted in the 73,162 matched
bytes. The registry still listed the label as its own entry because the
analyzer turns every BL target into a function. Its only reference is the BL at
080083BA, inside the owner: Thumb encodes a `goto` beyond branch range as BL
(`match-1102.md`, "Mapped entries reached by BL inside a function are far
jumps"). The 24-byte 08007B28 entry and the asm-only "recover the enclosing
body" notes were left over from before that match.
